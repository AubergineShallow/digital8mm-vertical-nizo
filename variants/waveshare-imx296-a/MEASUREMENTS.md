# Measurements and decisions to close

| ID | Required evidence | Why it blocks integration |
|---|---|---|
| WS-M1 | PCB FRONT to installed C-mount shoulder, with included adapter fully seated; drawing/photo identifying both datums; tolerance or repeated measurements | Establishes installed camera X; housing front is not the lens shoulder |
| WS-M2 | Sensor plane/backfocus or a reliable focus/engagement test for both D2 lenses; adapter face-to-face, diameter, spigot, thread engagement and any adjustment | Preserves infinity/near focus without inventing sensor height |
| WS-M3 | Hole pitch/location, actual PCB thickness, both-face component/copper keepouts around four Ø2.5 holes; mounting annulus diameter and isolation | Decides whether proposed M2 hardware/stand-offs can safely touch the board |
| WS-M4 | Housing-to-board attachment and permissible mounting torque/load or qualified practical load test | Avoids assuming the PCB is a structural mount for lens torque |
| WS-M5 | Exact camera CSI connector/latch position, outside size, hinge/open sweep, orientation, tool access | Replaces the official-camera endpoint and service envelope |
| WS-M6 | Received included cable length, width, thickness, stiffeners, contact orientation, bend limit | Determines whether existing corridor works without buying another cable |
| WS-M7 | Enclosure anchor and final loaded mount pose; panel/tool insertion/removal sequence | Completes the presently unanchored carrier's load path |
| WS-M8 | Actual 48/54 FPS full colour RAW10/manual-controls/DNG bench logs, dropped-frame counts, sustained media, power and heat tests | Vendor Pi 5 support is not D2 capture qualification |

User decision, after fit evidence: whether to approve a small additional M2
hardware set if the four-hole route proves preferable. Exterior enlargement or
another purchased cable remains a separate decision. No vendor contact has been
sent; no physical measurement has been claimed. Until these are resolved, the
project is a source-backed review variant with explicit holds.
