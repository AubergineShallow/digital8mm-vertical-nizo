## Windows path length

The longest repository-relative path is 132 characters (`cad/gs8-d2-v1/candidate-vertical/routing-snapshots/hdmi-ck1044-clear-20261009-0524/fps-deployed-carrier-context-0551-superseded.json`). Windows limits a full path to 259 characters, and git adds a `.lock` suffix while writing, so either clone into a folder whose own path is at most 120 characters, or enable long paths for the clone: `git config --global core.longpaths true` before cloning (and the Windows `LongPathsEnabled` policy for other tools). The routing-snapshot folder names are recorded in receipts and reconciler cases, so they are not shortened.
