# D2 vertical Pi concealed vent review candidate

This directory contains the compact Kowa / Princeton vertical-Pi camera candidate derived from [AubergineShallow/digital8mm](https://github.com/AubergineShallow/digital8mm), with upstream baseline commit `d38468e58eb2b02d56743e2e0cfdd8f780818a65` retained for traceability. The current ventilation study uses a plain integral outer skin and separate intake/exhaust shadow plenums. Broadside grilles are concealed; edge mouths remain visible in direct front/rear views. Compact storage has nine printed assembly rows and ten physical production prints, since the tub body and bonded catch stub print separately. Original storage has ten rows and eleven prints. The gauge and coupons are excluded; reviewed purchased selections/quantities remain unchanged.

**This is an unqualified review candidate, not a fabrication, energization or service release.** Every r7 physical gate that still applies to this layout, the candidate's G-V-* gates ([REVIEW](REVIEW.md)) and collar M1 remain open. Actual cooler registration, complete FPC/EVF wiring, real tool access, printed strength, plenum manufacture and closed-body thermal performance remain unresolved. Geometric openings and scoped CAD passes do not establish useful airflow or physical safety. The user-confirmed official Raspberry Pi Active Cooler remains selected. The detailed-Pi STEP versus approximate-cooler proxy/registration conflict does not establish hardware incompatibility; actual fit, fan-lead/service clearance, enclosure airflow and thermal performance remain unqualified.

## Reproduce a review snapshot

Use the selected Linux x86_64 runtime recorded in the manifest, the repository's pinned CadQuery environment from [the dependency lock](../../gs8-pxl-v3/cad-requirements-lock.txt) (candidate additions and optional extras: [requirements-candidate-lock.txt](requirements-candidate-lock.txt)) and the [CAD execution wrapper](../run_locked.py). [REPRODUCE.md](REPRODUCE.md) has the commands and Windows comparison limits. Linux-bound mesh caches are not promised to reproduce byte-for-byte on Windows; separate Windows exports require separate report identities. Read the scripts' arguments before running them, and keep all geometry sources fixed during export/checking.

1. Follow the ordered [reproduction instructions](REPRODUCE.md). Export all selected variants from frozen [model](model.py), [ventilation](vent_geometry.py) and recorded dependencies.
2. Refresh the saved plenum/context checks, independent local catch study, three plenum crops and structural calculation before the complete check-scope run. The structural calculation accepts a declared set of changed upper rows; a changed lower grip row uses a direct free body from bound STEPs. Unexpected changes are refused.
3. Run the selected serial [review checks](run_shadow_checks.py) and the alternative rigid/print/scope checks. Preserve every failure. Process exit zero does not imply aggregate acceptance; source identity, report status and physical qualification are separate.
4. Refresh BOM/wiring/assembly, renders, structural PDF and guide from settled reports. Inspect every rendered page before packaging. Record the blocked evidence set with `reconcile_review_evidence.py --record-blocked` while gates fail, then regenerate coverage/gates/index and run the document audit. The blocked receipt deliberately retains a nonzero acceptance status.

The guide and reports are review artifacts. Slicing, representative plenum/coupon tests, actual part measurements and powered qualification are separate work that has not been completed by these scripts.
