# D2 vertical Pi concealed vent review candidate

This directory contains the compact Kowa / Princeton vertical-Pi camera candidate derived from [AubergineShallow/digital8mm](https://github.com/AubergineShallow/digital8mm), with upstream baseline commit `d38468e58eb2b02d56743e2e0cfdd8f780818a65` retained for traceability. The current ventilation study uses a plain integral outer skin and separate intake/exhaust shadow plenums. Broadside grilles are concealed; edge mouths remain visible in direct front/rear views. Nine compact printed production parts and the reviewed purchased BOM selections/quantities are retained.

**This is an unqualified review candidate, not a fabrication, energization or service release.** Every r7 physical gate that still applies to this layout, the candidate's G-V-* gates ([REVIEW](REVIEW.md)) and collar M1 remain open. Actual cooler registration, complete FPC/EVF wiring, real tool access, printed strength, plenum manufacture and closed-body thermal performance remain unresolved. Geometric openings and scoped CAD passes do not establish useful airflow or physical safety.

**Print hold:** the tub is not print-released. Plenum trial2 (review FP-11a) carries the roof on continuous 1.2 mm flow ribs and splits all four edge mouths (cold rear Z5..75, cold underside, hot underside, hot front Z5..40) with mullions; the two cold mouths also have 45° lintels, the hot mouths cannot (area parity leaves 9.6 mm² of margin). On the trial2 tub every plenum roof and mouth region passes the computed single-direction bridge rule (longest plenum bridge 27.1 mm, hot underside zone; [run extracts](review-2026-10-10/fp11a/)), but other tub regions still fail it, the selected export predates trial2, and no slicer, coupon or physical bridge/cleanout result exists. The plenum coupon script now also crops all four mouths; its files must be regenerated from the final export.

## Evidence and preserved history

The current compact-Kowa [manifest](out/compact-kowa_lm6hc/manifest.json) identifies source files, STEP/mesh exports, estimated mass and print poses. Only reports whose manifest and verifier/source hashes match that export are current. The [documentation audit](out/review-docs-audit.json) distinguishes stale reports and checks BOM preservation. A report can contain known failures; binding a report does not convert them into passes.

[Reviewed export18](history/reviewed-export18/README.md) is the frozen reference before concealed-vent changes. Its raw 288 pass / 2 fail / 18 info result and prior service evidence remain historical. The new main checker distinguishes the intentionally empty CSI aperture from adjacent wall measurements; the actual cooler/source conflict remains an open hold.

The [visible angled-channel trial](vent-study/angled-channel-trial/manifest.json) is preserved as a rejected visual alternative. Its slot mouths remained visible, so its 59 mm core and throat/check results must not be used as the shadow-plenum result. Fresh [three-variant STEP comparisons](out/comparison/assembled-comparison.json) and core-void reports bind the current Kowa, Fujinon and original-storage exports. Compact Kowa/Fujinon bounding volumes are about 6.8% below matching baseline; original-storage Kowa is about 3.3% larger. Alternative exports and meshes have current identity checks, but compact-Kowa service results do not transfer.

## Reproduce a review snapshot

Use the repository's pinned CadQuery environment from [the dependency lock](../../gs8-pxl-v3/cad-requirements-lock.txt) (candidate additions and optional extras: [requirements-candidate-lock.txt](requirements-candidate-lock.txt)) and the [CAD execution wrapper](../run_locked.py). [REPRODUCE.md](REPRODUCE.md) has the exact commands for Windows and POSIX. Read the scripts' arguments before running them, and keep all geometry sources fixed during export/checking.

1. Export the chosen compact Kowa source with [export_candidate.py](export_candidate.py). Geometry is defined by [model.py](model.py), [vent_geometry.py](vent_geometry.py) and their recorded dependencies.
2. Run [verify_shadow_plenum.py](verify_shadow_plenum.py), then the serial [shadow review checks](run_shadow_checks.py). Preserve failures and inspect the report scope; do not inherit a historical pass count.
3. Refresh [the BOM generator](make_bom_vertical.py), [the CAD-free structural sensitivity](structural-review/update_concealed_vent_structure.py), the generated summaries ([coverage](make_coverage_vertical.py), [gates](make_gates_vertical.py), [repository index](make_repo_index.py), each with `--write`), and [the document/BOM audit](review_docs_audit.py). The structural calculation accepts only tub/panel changes relative to its frozen reference; a changed carried or lower component needs a new free-body calculation.
4. Rebuild [the structural PDF](structural-review/build_shadow_structural_pdf.py) from its bound JSON and text. For the pictorial guide, run [build_guide_concealed_vents.py](guide/build_guide_concealed_vents.py) under the CAD wrapper with `--manifest-sha256` set to the SHA-256 of the nominated `out/compact-kowa_lm6hc/manifest.json` (it changes with every re-export); on Windows run it through [run_with_numpy_raster.py](guide/run_with_numpy_raster.py), which supplies the pure-numpy rasterizer. Inspect every rendered page, then use [package_concealed_guide.py](guide/package_concealed_guide.py) to verify the guide package. A source change requires renewed bindings and renders.

The guide and reports are review artifacts. Slicing, representative plenum/coupon tests, actual part measurements and powered qualification are separate work that has not been completed by these scripts.
